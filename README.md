## merged open source work

| project | what changed |
|---|---|
| **[NestJS #18308](https://github.com/nestjs/nest/pull/18308)** | a module could start before the modules it depends on and shut down after them, so a service queried the database before the connection opened and after it closed; sorting 2,000 modules dropped from 260 ms to 1 ms |
| **[NestJS #18305](https://github.com/nestjs/nest/pull/18305)** | a valid route was dropped and returned 404 when a host list repeated a host |
| **[NestJS #18289](https://github.com/nestjs/nest/pull/18289)** | file type errors now report the type detected from the content, not the one the browser declared |
| **[Mastra #21067](https://github.com/mastra-ai/mastra/pull/21067)** | batched embedding requests: with 500 documents, calls dropped from 500 to 2 |
| **[Astro #18451](https://github.com/withastro/astro/pull/18451)** | running `astro sync`, `check` or `build` no longer breaks a running dev server |
| **[OpenTelemetry JS #7060](https://github.com/open-telemetry/opentelemetry-js/pull/7060)** | limits configured as zero no longer fall back to the default |
